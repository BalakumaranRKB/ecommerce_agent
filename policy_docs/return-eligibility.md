# Return Eligibility and Condition Requirements

Items may be returned within **30 days** of delivery provided they are in
resalable condition with all original packaging and accessories included. We
provide a prepaid return label at no cost for the first **2 returns** per
customer per calendar year; subsequent returns incur a **$6.99** label fee.
Once a return label is issued, the item must be handed to the carrier within
**14 days** or the return request expires automatically. Certain categories are
final sale and cannot be returned: gift cards, downloadable software, and
personal-care items whose seal has been broken.
